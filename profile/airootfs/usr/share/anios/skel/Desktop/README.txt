AniOS live session

Super+Return  Open terminal
Super+D       Open application launcher
Super+E       Open file manager
Super+Shift+E Exit the Hyprland session

Use the launcher to start Steam. Select "Install Immaterial Impulse" to
apply the optional upstream desktop (Internet connection required).

This is a temporary live session. Files and game installs may be lost at
shutdown unless you use persistent external storage.
